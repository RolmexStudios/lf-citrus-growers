# Shop template A

Static Next.js kit for a small shop. Page order lives in `src/app/page.tsx`: hero, a docking banner, a top-picks rail, then a close. Copy lives in `content/blueprint.json`.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The full catalog is [/shop](http://localhost:3000/shop). Each piece is `/shop/[slug]`.

See [CONTENT.md](./CONTENT.md).
